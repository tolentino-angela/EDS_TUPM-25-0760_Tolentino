# MAT-03: Electric Motor Vibration Anomaly Detection

Mechanical Engineering - Computer Programming and Fundamentals Final Project

---

## Project Overview

This project applies Data Analytics and Signal Processing techniques to analyze electric motor vibration data. The main objective is to detect abnormal vibration patterns that may indicate mechanical faults such as imbalance, misalignment, or bearing failure.

Vibration analysis is an important tool in predictive maintenance systems, allowing early detection of equipment degradation and preventing unexpected machine failure.

---

## Features

- **Data Pipeline:** Automated loading, preprocessing, and cleaning of vibration dataset.
- **Engineering Analytics:** Statistical analysis using Mean, Standard Deviation, and 3-sigma rule for outlier detection.
- **Anomaly Detection:** Identification and classification of normal and abnormal vibration signals using statistical thresholds.
- **Visualization:** Time-series plots of vibration signals with highlighted anomaly points.
